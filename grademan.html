Grade Manager Plus

Students check their own marks, and nobody else’s. Teachers get the view that shows who is slipping while there’s still term left to fix it.

GitHub Other projects

Accounts that hold

Separate student and teacher roles, so a login only ever opens the records it should.

Trends, not just totals

Charts across assessments make a downward slide obvious weeks before the final grade does.

Quick enough to use daily

Built so a teacher can check a class between periods rather than after hours.

How it’s built

A C# desktop application with a database behind it, structured around roles and permissions from the first commit rather than bolted on afterwards. Reporting reads from the same source the students do, so there is only ever one version of a mark.
