OpsRelay AI-assisted incident response, with a human in charge of every fix

OpsRelay watches running apps and, when one breaks, sends an agent to investigate. The agent reproduces the failure, works out what went wrong from the real logs and code, tests candidate fixes, and opens a pull request for a person to review. It never merges on its own.

  • Functional probes catch broken checkouts and messages, not just pages that return 200.
  • Every proposed fix has to pass the failing tests and the full suite before a PR exists.
  • I built NovaMart, NovaConnect and the first uptime monitor and status dashboard.
