Mobile · Flutter · In progress, fall 2026

Simply: receipt management

Paper receipts get lost, and return windows close without anyone noticing. Simply lets you photograph a receipt or type it in, review the details, and keep everything organised by store and category. It shows monthly spending by category and flags upcoming return and warranty dates.

The capture flow is built around a parser interface. The current build uses a mock parser, and swapping in a model-backed one is planned for the next milestone.

My part: the sign-in and sign-up screens with form validation, the shared receipt data model and mock data, and the central theme the team builds on.

E-Commerce Analytics Platform

Turns the public UCI Online Retail II dataset into revenue trends, top products and customer spending rankings. A React and TypeScript dashboard with Chart.js calls a Spring Boot REST API that does the SQL aggregation over MariaDB, all wired together with Docker Compose.

My part: troubleshooting the GitLab CI/CD pipeline (ESLint, Checkstyle, front-end tests, JaCoCo coverage), validating merges, and API and UML documentation across eight Scrum sprints.
