Earlier project · C# · Windows Forms · SQL

Grade Manager Plus

A desktop app for a small class. An administrator sees every student’s marks, averages and a marks graph, and can register new students. Students sign in and see only their own grades.

GitHub

Highlights

Two roles, two views

An administrator form with class-wide data and a student form limited to the signed-in student’s records.

Database-backed

Student records, marks and passwords live in a local database accessed through OleDb, including a forgot-password flow.

Visual reporting

A marks graph and per-student averages for the administrator.

What I’d change today

This was early coursework, and the login builds its SQL query by joining strings and compares plain-text passwords. Rebuilding it now, I’d use parameterised queries everywhere, store salted password hashes, and make roles a property of the account rather than a special username. Writing that down is part of the point: this is the code I learned from.
