Hotel concierge chatbot

Front desks answer the same questions every day. This assistant handles them in plain language at any hour, so staff can focus on the guest standing in front of them.

Highlights

Understands the question

Guests ask in everyday language, with no menus and no guessing at keywords.

Stays in scope

A prompt layer keeps answers to what the hotel actually offers.

Knows its limits

Unusual requests go to a person, with the context already collected.

It’s built with Python and Flask on the server and the OpenAI API for language understanding. The most important design decision was what the assistant should not try to answer. I took that idea further in OpsRelay, where the agent hands anything it can’t prove to a person.
